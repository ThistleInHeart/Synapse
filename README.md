**Synapse** — это открытый проект искусственного интеллекта для **The Sims 4**, оживляющий персонажей с помощью нейросетей нового поколения. Мод генерирует спонтанные мысли, монологи в реальном времени, живые диалоги тет-а-тет и переписки в мессенджере с долговременной памятью.

## 🛡️ Открытый исходный код и безопасность (Заявление о ложных срабатываниях антивирусов)

Некоторые пользователи могли столкнуться с предупреждениями антивирусов (Windows Defender, Chrome) при скачивании собранных бинарных файлов (`Synapse.exe` / `ai_bridge.exe`).

### Почему это происходит:
1. **Упаковка через PyInstaller:** Готовые бинарные файлы собираются утилитой PyInstaller. Большинство современных эвристических сканеров автоматически помечают неподписанные упакованные Python-интерпретаторы общими маркерами (такими как `Win32/Wacatac` или `Heur.Boring`), если у разработчика нет платного цифрового сертификата безопасности (Code Signing Certificate, стоящего $400+/год).
2. **Локальный веб-сервер:** Мост создаёт локальный сокет на `127.0.0.1:8765` для приёма запросов из The Sims 4. Антивирусные эвристики могут настороженно относиться к программам, открывающим локальные сетевые порты.

### Полная прозрачность:
- **Никаких скрытых бинарников:** Этот репозиторий содержит **100% исходного кода** проекта без какой-либо обфускации.
- **Запуск напрямую из Python:** Вы можете вообще **не использовать никакие `.exe` файлы**! Установите обычный Python и запустите проект командой `python launcher.py`. Вы получаете абсолютно тот же функционал при 100% контроле над исполняемым кодом.
- **Полная локальность:** Все соединения происходят строго между игрой The Sims 4, локальным мостом `127.0.0.1` и выбранным вами API-провайдером (или локальной нейросетью на вашем ПК без выхода в интернет).

## 🚀 Быстрый старт (Запуск из исходников)

### 1. Запуск моста и интерфейса Synapse
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/<ваш-аккаунт>/Synapse.git
   cd Synapse/Bridge
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите лаунчер:
   ```bash
   python launcher.py
   ```
4. В открывшемся окне настройте нужный провайдер (OpenAI, Gemini, Anthropic, DeepSeek, Groq или локальный LM Studio / Ollama) и запустите мост.

### 2. Установка мода в игру
Вы можете собрать мод самостоятельно:
```bash
cd ../Sims4Mod
python build_mod.py
```
Скрипт скомпилирует `.ts4script` файлы и положит их в папку `Sims4Mod/build` (а также автоматически скопирует в вашу папку `Mods\Synapse`, если игра установлена).
