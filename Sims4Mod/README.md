# 🎮 Synapse The Sims 4 Mod (Python Scripts & Gameplay Package)

Скриптовый мод для **The Sims 4**, интегрирующий искусственный интеллект в игровой процесс.

---

## 📁 Архитектура мода

### 1. `ai_thought_reader` (`Synapse_SimMind.ts4script`)
- **Контекстный анализатор:** Считывает черты характера, возраст, расу, текущее действие, настроение, окружение, погоду, город/локацию (в помещении/во дворе/в заведении), отношения и семейные связи.
- **Генератор мыслей:** Создаёт живые внутренние монологи симов в реальном времени от первого лица, отображая их в облачках мыслей (speech balloons) и всплывающих уведомлениях.
- **Поддержка питомцев:** Отдельная система генерации мыслей и реакций для кошек и собак.

### 2. `ai_social_pc` (`Synapse_SocialMessenger.ts4script`)
- **Мессенджер на компьютере и телефоне:** Личные и групповые переписки симов с NPC через ИИ.
- **Живые диалоги тет-а-тет:** Полноценное общение персонажей при взаимодействиях с сохранением контекста разговора.
- **Долговременная память:** Сохранение воспоминаний о важных событиях (пожары, свадьбы, измены, признания, драки) в файле сохранений игры.

### 3. `Synapse_Interactions.package`
- Пакет игровых ресурсов (tuning XML / STBL), добавляющий социальные взаимодействия, меню на компьютере и опции вызова мыслей.

---

## 🛠️ Сборка мода из исходников

Движок The Sims 4 использует встроенный интерпретатор **Python 3.7.9 (64-bit)**. Компиляция `.py` в `.pyc` байткод должна производиться именно под **Python 3.7**!

### Инструкция по сборке:
1. Установите **Python 3.7.9 (x64)** (если он ещё не установлен).
2. Запустите скрипт сборщика:
   ```bash
   python build_mod.py
   ```
3. Скрипт автоматически:
   - Проверит и синхронизирует локализации (`sync_mod_translations.py`).
   - Скомпилирует все исходники `.py` в `.pyc` под Python 3.7.
   - Упакует их в zip-архивы с расширением `.ts4script` в папку `build/`.
   - Скопирует готовые файлы (`Synapse_SimMind.ts4script`, `Synapse_SocialMessenger.ts4script`, `Synapse_Interactions.package`) в вашу папку `The Sims 4\Mods\Synapse` (если игра установлена).
