# 🧠 Synapse Bridge (Desktop Client & Local AI Gateway)

**Synapse Bridge** — это локальное связующее звено между игрой **The Sims 4** и современными моделями искусственного интеллекта (OpenAI GPT, Google Gemini, Anthropic Claude, DeepSeek, Groq, а также локальными нейросетями через LM Studio и Ollama).

---

## 🔒 Безопасность и открытый исходный код

- **100% открытый код:** Все скрипты написаны на стандартном Python и открыты для полного аудита.
- **Работа исключительно на `localhost`:** Сервер моста слушает только локальный адрес `127.0.0.1:8765`.
- **Прямое соединение с API:** Запросы отправляются напрямую с вашего компьютера к выбранному провайдеру ИИ (или к локальной модели в вашей сети).
- **Никакой телеметрии и скрытых данных:** В коде отсутствуют скрытые сетевые вызовы, сбор аналитики или сторонние серверы.

---

## 📁 Структура модуля

- `ai_bridge.py` — Высокопроизводительный локальный HTTP-сервер на стандартной библиотеке Python. Принимает структурированный контекст из игры The Sims 4, формирует промпты, отправляет запросы к нейросетям и возвращает сгенерированные ответы, мысли и диалоги обратно в игру.
- `launcher.py` — Графический интерфейс (GUI) на `customtkinter`, позволяющий настраивать API-ключи, выбирать модели, тестировать подключение и управлять параметрами мода.
- `localization_manager.py` — Движок мультиязычности для интерфейса лаунчера.
- `languages/` — Языковые файлы интерфейса и игровых строк (`RU.txt`, `EN.txt`, `mod_strings/`).

---

## 🚀 Запуск из исходного кода

Вам не нужно запускать бинарные файлы (`.exe`). Вы можете запустить мост напрямую через чистый интерпретатор Python:

### 1. Требования
- Python 3.8+ (рекомендуется Python 3.10, 3.11 или 3.12)

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск GUI-лаунчера
```bash
python launcher.py
```

### 4. Запуск моста в фоновом/консольном режиме (без GUI)
```bash
python ai_bridge.py
```
Сервер запустится на `http://127.0.0.1:8765`.
